# AGENTS.md

Contribution rules for this copier template, for humans and AI agents alike.
`template/AGENTS.md.jinja` holds the rules for generated projects.
A rule there that also fits this repository applies here too.

## Markdown line breaks

Always write one sentence per line in every Markdown file, including the `*.md.jinja` files under `template/`.
Split a very long sentence at a clause boundary, so that each line holds one clause.
Never wrap lines at a fixed width.
A diff then shows the sentence that changed, not a reflowed paragraph.
Code blocks, tables and headings keep their own form.
